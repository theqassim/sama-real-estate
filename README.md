# موقع سما العقارية

موقع + لوحة تحكم. بتضيف وتعدّل وتحذف العقارات من المتصفح وترفع صورها، من غير ما تلمس الكود.

## التشغيل على VS Code

1. نزّل **Node.js** (نسخة LTS) من https://nodejs.org لو مش عندك.
2. افتح فولدر `sama-realestate` في VS Code (File ← Open Folder).
3. افتح التيرمنال (Terminal ← New Terminal) واكتب:

```bash
npm install
npm start
```

4. افتح في المتصفح:
   - الموقع: **http://localhost:3000**
   - لوحة التحكم: **http://localhost:3000/admin/**

الباسورد الافتراضي: `sama2026`

> مهم: لازم تفتح الموقع من `localhost:3000` بعد `npm start`. لو فتحت `index.html` مباشرة أو بـ Live Server مش هيحمّل العقارات، لأن العقارات بتيجي من السيرفر.
> وأثناء التعديل في الكود استخدم `npm run dev` عشان السيرفر يعيد التشغيل لوحده.

## من لوحة التحكم

- **العقارات:** إضافة، تعديل، إخفاء/إظهار، حذف، ورفع صورة لكل عقار.
- **إعدادات الموقع:** رقم الواتساب (بالصيغة الدولية مثل `201012345678`) والعنوان. بيتغيروا في الموقع كله.
- لو عقار من غير صورة، بتظهر رسمة معمارية مؤقتة حسب نوعه.
- الفلاتر فوق العقارات (شقق / فيلات / تجاري...) بتظهر لوحدها حسب العقارات الموجودة.

العقارات الستة الموجودة دلوقتي أمثلة للتجربة، امسحها من لوحة التحكم وضيف عقاراتكم.

## غيّر الباسورد

افتح ملف `.env` وغيّر `ADMIN_PASSWORD`، وبعدها أعد تشغيل السيرفر. **لازم تغيّره قبل ما ترفع الموقع أونلاين.**

## شكل الملفات

```
server.js               السيرفر وAPI العقارات ورفع الصور
.env                    الباسورد والبورت
data/properties.json    بيانات العقارات
data/settings.json      رقم الواتساب والعنوان
public/index.html       الصفحة الرئيسية
public/css/style.css    التصميم والألوان
public/js/main.js       السحاب وخط المدينة والحركة
public/js/art.js        الرسومات المؤقتة للعقارات
public/js/types.js      أنواع العقارات وأقسامها
public/js/properties.js تحميل العقارات وعرضها
public/admin/           لوحة التحكم
public/uploads/         الصور اللي بترفعها
```

## تغييرات شائعة

- **الألوان:** أول ملف `style.css` (متغيرات `:root`).
- **النصوص:** `public/index.html`.
- **نوع عقار جديد (مثلاً "عمارة"):** ضيفه في `public/js/types.js` وفي مصفوفة `TYPES` أول `server.js`.

## النشر أونلاين

المشروع محتاج استضافة بتشغّل Node.js (مثل Render أو Railway أو VPS):
أمر التشغيل `npm start`، ومتغيّر البيئة `ADMIN_PASSWORD`.
خلّي بالك إن الاستضافات المجانية أحياناً بتمسح الملفات عند إعادة التشغيل، فاستخدم **Persistent Disk** لفولدرَي `data` و`public/uploads`، وخد منهم نسخة احتياطية بشكل دوري.
